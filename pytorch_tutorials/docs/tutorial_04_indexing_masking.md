## 核心概念

- 索引用来取局部数据，切片常用于 batch、序列、图像区域。
- 布尔 mask 可以筛选满足条件的元素，是处理异常值、条件统计的常用手段。
- 训练中经常会按标签、置信度、padding mask 来选择样本或位置。

## 理解思路

写 PyTorch 代码时，先不要把注意力放在“背 API”上，而是先问四个问题：

1. 数据是什么形状？例如 `[batch, features]`、`[batch, time, features]` 或 `[N, C, H, W]`。
2. 标签是什么类型？回归通常是浮点，分类通常是整数类别编号或 0/1 浮点标签。
3. 模型输入和输出应该是什么 shape？loss 函数会严格要求它们匹配。
4. 哪些张量需要梯度，哪些只是数据或指标？不要让日志、评估和保存逻辑干扰计算图。

## 关键写法速查

| 写法 | 什么时候用 |
| --- | --- |
| `x[i]`<br>`x[-1]` | `x[i]` 取第 i 行或第 i 个元素；索引从 0 开始，`x[-1]` 表示最后一个。 |
| `x[:, 0]`<br>`x[1, :]` | `x[:, 0]` 取所有行的第 0 列；`x[1, :]` 取第 1 行所有列。 |
| `x[:, :3]`<br>`x[::2]` | `x[:, :3]` 取所有行的前 3 列；`x[::2]` 每隔一个取一次。 |
| `x[start:end]`<br>`end` | `x[start:end]` 左闭右开，不包含 `end` 位置。 |
| `mask = x > 10`<br>`x[mask]` | `mask = x > 10` 会得到布尔张量；`x[mask]` 会筛出满足条件的元素。 |
| `torch.where(condition, a, b)` | `torch.where(condition, a, b)` 按条件从 a/b 中选值，适合做条件替换。 |
| `x.argmax(dim=1)` | `x.argmax(dim=1)` 常用于从分类 logits 得到预测类别。 |
| `x.gather(dim, index)` | `x.gather(dim, index)` 可以按 index 收集元素，常见于更复杂的分类或序列任务。 |
| `x.scatter_(dim, index, value)`<br>`_` | `x.scatter_(dim, index, value)` 可以按 index 写入，函数名带 `_` 表示原地修改。 |
| `x[mask] = 0` | 原地修改如 `x[mask] = 0` 很方便，但在 autograd 计算图里要谨慎，可能破坏梯度需要的中间值。 |

## 常见排错表

| 现象 | 优先检查 |
| --- | --- |
| shape 报错 | 打印参与运算的所有张量 shape，按维度逐个对齐 |
| dtype 报错 | 分类标签通常要 `torch.long`，回归值和模型输入通常要浮点 |
| device 报错 | 模型、输入、标签必须在同一个 device |
| loss 不下降 | 检查是否执行了 `zero_grad()`、`backward()`、`step()`，学习率是否过大或过小 |
| 指标奇怪 | 确认标签含义、输出 shape、阈值或 `argmax(dim=...)` 是否写对 |
